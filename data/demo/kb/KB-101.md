# Unlock a CAD file that is checked out by someone else

A file stays locked while another user has it checked out. Only that user, or a vault administrator, can release it.

## If the person is available
1. In the CAD vault client, right-click the file and choose **Properties > Checked out by** to see who has it.
2. Ask them to check the file in, or to choose **Undo check-out** if they made no changes.

## If the person has left or is away
1. Open a ticket in the **CAD Vault Support** queue with the file name and the user shown in **Checked out by**.
2. A vault administrator can force an undo check-out. Their unsaved local changes are lost, so the administrator first asks the user's manager to confirm.

Never copy the file to a new name to work around a lock: that creates a duplicate part.
