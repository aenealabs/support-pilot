# Restore a previous version of a CAD file

Every check-in creates a version. To go back:
1. Right-click the file and choose **History**.
2. Select the version and choose **Get this version**, then check it in as the latest.

Released files cannot be overwritten. To change a released file, start an ECO (see KB-201).
