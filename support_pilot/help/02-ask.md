# Ask

Answers come only from the knowledge base, and every step shows where it came from.

## Asking a question

Type the question as you would to a colleague. Code finds the most relevant article
passages; the AI answers only from them, quoting a passage for every step. Code checks each
quote word for word: a step whose quote is not in its passage is removed, and the removal is
shown.

## When the answer is withheld

If the articles do not cover the question, no answer is shown rather than a guess. You get a
ready-to-paste ticket that says what was searched, so the support team starts with context.

## Did it help?

Every question is logged as answered or withheld, and you can say whether the answer solved
the problem. That is how deflection is measured.
