# Search for an existing part before creating a new one

Creating a part that already exists causes duplicate inventory and qualification work.

1. Use **Search > Parts > Advanced** and search by **Classification** first, then size and material; descriptions vary between engineers.
2. Include obsolete parts in the search and check **Superseded by**.
3. If you find a likely match in another business unit, use it; ask its owner if anything is unclear.

The data steward team reviews new parts for duplicates weekly.
